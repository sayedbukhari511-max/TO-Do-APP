# 📝 To-Do List App

A simple, clean, and responsive **To-Do List Web App** built using **HTML, CSS, and JavaScript**.

This project helps users manage their daily tasks by adding, completing, and deleting tasks through an easy-to-use interface.

## 🚀 Features

* ➕ Add new tasks
* ✅ Mark tasks as completed
* 🗑️ Delete tasks
* 📱 Responsive design
* 🎨 Clean and simple UI
* ⚡ Fast and lightweight
* 💻 Works directly in the browser

## 🛠️ Technologies Used

* **HTML5** – Structure
* **CSS3** – Styling and responsive design
* **JavaScript** – Functionality and task management

## ▶️ How to Run

1. Clone the repository:


git clone YOUR_GITHUB_REPOSITORY_URL


2. Open the project folder.

3. Open `in.html` in your browser.

### Using VS Code

You can also use the **Live Server** extension:

1. Open the project in VS Code.
2. Right-click `in.html`.
3. Select **Open with Live Server**.
4. The app will open in your browser.
